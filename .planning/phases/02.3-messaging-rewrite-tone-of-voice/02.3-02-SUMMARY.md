## Decisions Made

**Benefits reduction and reframing:** Changed from 8 feature-oriented advantages (timeSaving, noScaffolding, fireResistant, lightweight, antiCorrosion, vaporPermeable, flexible, wideTemp) to 5 outcome-oriented benefits focused on customer results (personnel safety, application without shutdown, corrosion protection, versatile application, cost effectiveness). This aligns with problem-first messaging established in Plan 01.

**Cooperation workflow timeline design:** Desktop layout uses horizontal 4-column grid with numbered circles connected by visual line. Mobile layout uses vertical stack with numbered circles and connecting lines on left side. This ensures readability on all devices.

**Hero description approach:** Product hero now describes TC101 as "ceramic coating with hollow microspheres" applied on 5 surface types. This gives visitors immediate context (what it is) before diving into benefits (what it does).

**CTA language specificity:** Updated from generic "Request a quote" / "Poptat" to "Request technical consultation" / "Požádejte o technickou konzultaci". This frames UNION B+C as technical partner, not just vendor.
