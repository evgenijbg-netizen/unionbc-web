**Step 2: Add Image component to product hero section.**

Update `src/components/product/HeroSection.astro`:
1. Add import: `import { Image } from 'astro:assets';`
2. Add import for product photo: `import productPhoto from '../../assets/images/products/tc101-application.jpg';`
3. Add the Image component next to the hero text content, in a 2-column grid layout on desktop:

```astro
<Image
  src={productPhoto}
  alt={t(locale, "product.hero.imageAlt")}
  width={600}
  height={400}
  format="webp"
  quality={85}
  class="rounded-lg shadow-lg w-full h-auto"
  loading="eager"
/>
```

If `product.hero.imageAlt` key doesn't exist in i18n files, add it:
- cs.json: `"product.hero.imageAlt": "Aplikace TEMP-COAT TC101 na průmyslovém potrubí"`
- en.json: `"product.hero.imageAlt": "TEMP-COAT TC101 application on industrial piping"`

Make the hero section a responsive grid: single column on mobile (image below text), two columns on md+ (text left, image right).

**Step 3: Add a product image to the homepage.**

Update both `src/pages/cs/index.astro` and `src/pages/en/index.astro`:
1. Import Image component and product photo
2. Add the product image to an appropriate section (hero area or "Why TC101" section)
3. Use responsive sizing: `width={500}` on desktop, full-width on mobile

Keep changes minimal -- one image placement per page. Do NOT restructure the entire homepage layout.

**Important:** If the legacy photos are too low-quality (very small, blurry, or just icons/decorative elements), note this in the summary and skip the Image integration. The palette change and claims audit are the priority deliverables. Image integration is valuable but not blocking.
