  <name>Task 1: Update @theme to light professional OKLCH palette</name>
  <files>src/styles/global.css</files>
  <action>
Replace the current dark industrial @theme color values with a light professional palette using OKLCH. Keep the SAME variable names (--color-surface-900, --color-surface-800, etc.) but give them light-mode appropriate values. This is the "Option B" approach from research -- we keep semantic meaning correct (surface-50 = lightest, surface-900 = darkest) and update component classes in Task 2.

New @theme values:

```css
@theme {
  /* Light professional palette -- OKLCH for perceptual uniformity */

  /* Surfaces: 50 = lightest (page bg), 900 = darkest (header/footer) */
  --color-surface-900: oklch(0.15 0.01 250);  /* Darkest -- header, footer */
  --color-surface-800: oklch(0.22 0.01 250);  /* Dark sections, nav */
  --color-surface-700: oklch(0.30 0.01 250);  /* Dark borders, hover */
  --color-surface-600: oklch(0.40 0.01 250);  /* Muted elements */
  --color-surface-200: oklch(0.90 0.005 250); /* Card backgrounds */
  --color-surface-100: oklch(0.95 0.005 250); /* Alternate section bg */
  --color-surface-50: oklch(0.98 0.002 0);    /* Primary page background -- near-white, neutral */

  /* Accent: professional blue, increased chroma for visibility on light */
  --color-accent-600: oklch(0.50 0.18 250);   /* Active/pressed state */
  --color-accent-500: oklch(0.58 0.18 250);   /* Primary buttons, links */
  --color-accent-400: oklch(0.68 0.15 250);   /* Hover state, highlights */

  /* Warning/CTA: warm amber, slightly deeper for light bg contrast */
  --color-warn-500: oklch(0.70 0.18 65);

  /* Text: dark on light -- inverted from current */
  --color-text-primary: oklch(0.20 0.01 250);   /* Main body text -- dark */
  --color-text-secondary: oklch(0.45 0.01 250); /* Secondary/muted text */
  --color-text-dark: oklch(0.15 0.01 250);       /* Headings, emphasis */
  --color-text-light: oklch(0.95 0.005 250);    /* Text on dark backgrounds (header/footer) */

  /* Typography, spacing, breakpoints -- UNCHANGED */
  --font-heading: "Space Grotesk Variable", ui-sans-serif, system-ui, sans-serif;
  --font-body: "Inter Variable", ui-sans-serif, system-ui, sans-serif;
  --spacing: 4px;
  --breakpoint-sm: 640px;
  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
  --breakpoint-xl: 1440px;
}
```

Key decisions:
- surface-50 uses chroma 0 (true neutral white) for page background -- no blue tint
- surface-900/800 KEEP their dark values (header/footer stay dark for contrast framing)
- NEW --color-surface-200 and --color-surface-600 added for card backgrounds and muted elements on light palette
- NEW --color-text-light added for text that appears on dark backgrounds (header, footer, overlays)
- Accent chroma maintained at 0.18 for visibility on light backgrounds
- text-primary inverted from oklch(0.95...) to oklch(0.20...) for dark-on-light readability
  </action>
