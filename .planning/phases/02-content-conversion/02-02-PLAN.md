    **FaqAccordion.astro:**
    - Uses `<details>` elements with shared `name` attribute per category for exclusive accordion (only one open at a time within each category)
    - 4 categories based on research content inventory:
      1. **Application and usage** (~5 questions): Where TC101 is used, how much to apply, application method, layer thickness, primer requirements
      2. **Technical properties** (~4 questions): Temperature range, expansion/contraction, weight after application, drying time
      3. **Maintenance and durability** (~3 questions): Cleaning, curing, shelf life
      4. **Safety and certification** (~4 questions): Personal protection, flammability, Czech certifications, material compatibility
    - Total: ~16 curated questions (not all 22 from old site -- merge redundant ones, remove irrelevant ones per research recommendation)
    - Each category: h2 heading + list of `<details>` items
    - Summary styling: `py-4 px-2 cursor-pointer font-medium flex justify-between items-center` with chevron SVG that rotates on open (`group-open:rotate-180`)
    - Answer styling: `pb-4 px-2 text-text-secondary leading-relaxed`
    - Border between items: `border-b border-surface-700`
    - Component accepts `locale: Locale` prop
    - FAQ structure defined as array of categories with question IDs, content from translation keys

    **Translation keys pattern:**
    - `faq.meta.title`, `faq.meta.description` -- page meta
    - `faq.page.title`, `faq.page.subtitle` -- page heading
    - `faq.category.{categoryId}` -- category name
    - `faq.{qId}.question` -- question text
    - `faq.{qId}.answer` -- answer text (can be multi-sentence, plain text)

    **Content rules:**
    - Questions and answers written from scratch in native Czech and English
    - DO NOT copy phrasing from the old site (www/tcold/faq.html) -- use it only as FACT SOURCE
    - Czech: natural question phrasing a Czech engineer would ask, not translated Russian
    - English: natural professional English, not translated Czech
    - Technical answers should be specific: include numbers, temperatures, time durations where relevant
    - Reference Czech certifications where applicable (safety data sheet, product certificate)

    **Page files (cs/faq.astro and en/faq.astro):**
    - Thin shells: BaseLayout with pageKey="faq", page heading from SectionHeading, then FaqAccordion component
    - Meta title/description from faq.meta.* keys
    - Max-w-3xl container for readability (FAQ is text-heavy, narrow width is better)
